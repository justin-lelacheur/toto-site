100% open-source commitment

Open source. By commitment.

toto commits toto foundry to a free and open-source core, so customers can inspect the foundation, avoid opaque lock-in, and retain a meaningful path to operate and extend it themselves.

The core is built with platform-defining open-source programs: Apache Kafka for events, Temporal for durable workflows, Neo4j and Protégé for ontology work, LangGraph for bounded AI, and FastAPI, Keycloak, OpenFGA, and Open Policy Agent for the integration and control plane.
