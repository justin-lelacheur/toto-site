# The Server-Driven Experience Studio

## The Omni-Channel Interface Canvas for Conversational Design

The **Server-Driven Experience Studio** gives people and agents a shared workspace for shaping operational experiences. Operators set intent through visual design or conversation; agents can propose layouts, identify missing context, and prepare changes for review without taking control away from the people accountable for the outcome.

---

## Key Architectural Features

* **Zero-Dependency Ryu Renderer:** Leverages a lightweight, pre-compiled browser shell that bans unsafe client-side evaluations (`eval()`), rendering layouts on demand from server-delivered **chunked JSON metadata**.
* **WebRTC Streaming Speech Broker:** Integrates an isolated bi-directional WebSocket audio pipeline that captures microphone inputs and passes raw PCM audio data straight to an asynchronous speech-to-intent engine.
* **Rigid 4px/8px Grid Layout Matrix:** Imposes exact visual design token boundaries, forcing all padding, margins, borders, and layouts to align onto a mathematical layout grid.
* **Tabular Layout Stabilization:** Enforces CSS font-variant properties (`.ryu-tabular-nums`) across all data screens, locking all numerical inputs into identical horizontal widths to eliminate visual layout shifts during real-time updates.

---

## Core Business Benefits

* **Faster human-agent collaboration:** Shifting layouts, building fields, or changing tracking masks becomes a guided conversation between operator intent and agent assistance rather than a queue of disconnected frontend tickets.
* **Hands-Free Operational Velocity:** Field operators and compliance managers can adjust workflows on the fly simply by speaking naturally to their workstation canvas.
* **Unified Brand and Visual Consistency:** Because the layout engine restricts rendering to pre-approved style tokens, pages generated by the AI Software Factory maintain identical corporate design guidelines.
