	<header class="product-page__hero">
		<p class="product-page__eyebrow">The AI software factory</p>
		<h1>AI that can help. Never run ahead.</h1>
		<p class="product-page__lead">toto foundry treats AI as a bounded enterprise capability: useful enough to accelerate the work, controlled enough to earn a place in it.</p>
	</header>

	<section class="product-page__section">
		<p class="product-page__kicker">Roles, not a super-agent</p>
		<h2>Give each agent one clear job.</h2>
		<div class="product-grid product-grid--two">
			<article class="product-grid__item">
				<h3>Domain agent</h3>
				<p>Retrieves authorized context, classifies a request, and proposes the domain information or next action that is needed.</p>
			</article>
			<article class="product-grid__item">
				<h3>Workflow design agent</h3>
				<p>Turns approved intent into a draft state model, workflow definition, and integration dependency map.</p>
			</article>
			<article class="product-grid__item">
				<h3>Validation agent</h3>
				<p>Checks proposed changes against semantic constraints, policy rules, contracts, and test evidence.</p>
			</article>
			<article class="product-grid__item">
				<h3>Governance review agent</h3>
				<p>Prepares an explainable risk summary and required approval path. It cannot approve its own output.</p>
			</article>
		</div>
	</section>

	<section class="product-page__section product-page__section--tint">
		<p class="product-page__kicker">Tools have contracts</p>
		<h2>No invisible permissions.</h2>
		<p class="product-page__body">Every tool declares its input and output schema, authorization scope, side-effect class, timeout, retry behavior, idempotency key, audit event, and approval requirement. Tools that create, modify, deploy, or delete production artifacts remain behind a Temporal workflow and a successful policy decision.</p>
	</section>

	<section class="product-page__section">
		<p class="product-page__kicker">Autonomy, explicitly chosen</p>
		<h2>More capability only when the evidence supports it.</h2>
		<ol class="product-steps">
			<li><strong>Advisory</strong><span>AI returns analysis, drafts, evidence, and recommendations for a person to consider.</span></li>
			<li><strong>Assisted</strong><span>AI can create sandbox artifacts that require review before any promotion or material effect.</span></li>
			<li><strong>Controlled</strong><span>AI may invoke pre-approved, idempotent tools inside an authorized workflow with the required approvals.</span></li>
		</ol>
	</section>

	<section class="product-page__section product-page__section--ink">
		<p class="product-page__kicker">Evidence by default</p>
		<h2>Every run leaves a record worth reviewing.</h2>
		<p class="product-page__body">toto foundry records the graph and prompt version, model, retrieval references, tools, policy decision, reviewer decision, and workflow outcome. Model or agent changes are governed releases with evaluation, security review, cost limits, and rollback.</p>
